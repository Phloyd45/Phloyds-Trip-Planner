Fuel cost estimate
Calculate a route first — this fills in with fuel prices detected for each country you'll cross.
Prices are rough recent averages by country, not a live feed — edit any row to match prices you know are current. Electric charging cost is a single rate since roadside prices vary far more than fuel does. Fill-up stops search OpenStreetMap for up to 3 fuel or charging options within 20 miles of each calculated point along your route — always double-check a station is open/compatible before relying on it.
Toll cost estimate
Calculate a route first — this fills in with a rough toll estimate for each country you'll cross.
Rough averages, not a live tolling feed — motorway tolls are estimated per km driven in that country, vignette countries (e.g. Switzerland, Austria) show a flat trip charge, and countries that are mostly toll-free default to £0. Edit any row to match a route you know, or zero one out if you're avoiding toll roads — this tool doesn't know which specific roads your route uses, only which countries it passes through.
Routing via OSRM · Geocoding & nearby towns via OpenStreetMap Nominatim and Overpass. Driving times are engine estimates (no traffic, stops or borders factored in) — treat them as a planning starting point.
